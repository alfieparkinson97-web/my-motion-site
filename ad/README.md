# Kits4U: "Launching 20.10" TikTok ad

| File | What it is |
| --- | --- |
| `kits4u-launch.mp4` | The ad. 1080×1920 (9:16), 30 fps, 25.0 s, H.264 + silent AAC track (no music). |
| `kits4u-cover.png` | 1080×1920 cover image: the exact final frame (end card). |
| `kits4u-ad.html` | The animated ad as one self-contained HTML file (fonts, site screenshots and site code inlined). Open it in a browser to preview. |
| `src/`, `tools/` | Source and the build/record pipeline (see the end of this file). |

The ad runs on the website's own code, inlined unmodified: `assets/js/gl.js` (the floodlit digital stadium, the giant flag football and the small flag-football orbs), `flags.js`, `jersey.js` and `data.js` (8 nations, 27 kits). The website montage uses real screenshots of the storefront taken at phone size.

Brand: pitch black `#05070a`, volt `#c9f24a`, white type. Prata for headlines, Hanken Grotesk for body text, and Poppins for the **kits4u** logo with "4u" in volt. Jerseys are generated Kits4U designs in national colours. The ad never calls them "official", and it shows no club, federation or brand logos.

For a 120–128 BPM sound, line up the **drop** with the first flag snap at **2.0 s** and let the rest fall roughly on the half-beats. ### TikTok safe zone

All copy sits inside x 60–940 px and y 150–1500 px, so nothing important is in the top 150 px, the bottom 420 px (caption/music bar) or the right 140 px (like/comment/share buttons). Only decorative elements (the ball, turf, phone edge, orbs) go into those areas. Open `kits4u-ad.html?safe` (or press **S** in the preview) to see the zones drawn over the ad.

## Rebuilding

Requirements: Node 18+, ffmpeg, and Playwright with Chromium (`npm install` in this folder, then `npx playwright install chromium` if you don't already have a browser).

```bash
cd ad
npm run fonts     # (once) download Prata / Hanken Grotesk / Poppins woff2 into src/fonts
npm run shots     # (once, or after site changes) phone-size screenshots of the live site into src/shots
npm run record    # build kits4u-ad.html, then render kits4u-launch.mp4 + kits4u-cover.png
npm run stills -- 2.0,14.2,24.9   # render review PNGs at given times into stills/
```

How it works: `renderAt(t)` in `src/ad.js` poses everything for time `t`. The recorder steps through all 750 frames one by one, screenshots each in headless Chromium and pipes lossless PNGs into ffmpeg. Frames are rendered, not captured in real time, so the video can't drop or duplicate frames. During recording, every frame is also checked for text outside the frame or the safe zone. The report goes to `stills/audit.json`.

Edit copy and timing in `src/ad.js` (the `T`, `SNAPS`, `IMPACTS` and `FLASHES` tables) and layout in `src/ad.html`. Never edit `kits4u-ad.html` directly, because it's regenerated by the build.
